# DocuScope CA Sample Corpus

The directory `test_corpus/` contains a curated set of fifty short academic prose samples that accompany the DocuScope CA submission to the *Journal of Open Source Software*. The texts were prepared by David West Brown from publicly available university writing samples and lightly edited to remove personally identifiable information.

- **Purpose**: Exercising the headless processing pipeline and reproducing the example workflow described in the paper.
- **Scope**: Each file (`acad_*.txt`) represents a single document. The collection totals ~150k tokens once parsed with the bundled DocuScope models.
- **Provenance**: Compiled specifically for this project; no third-party licensing restrictions are attached.
